OpenJooki

Update or install OpenJooki on your Jooki v2 — from your phone, no computer.

Phone on the same Wi-Fi as the Jooki. Dots or commas both work — and this page remembers it next time.
How do I find my Jooki's IP?
  • Easiest — the Jooki app: open it, pick your Jooki, go to its Device / Settings screen; the IP is shown there.
  • Your Wi-Fi router: open its page (often 192.168.1.1) → Connected devices → look for a name starting with jooki.
  • It looks like 192.168.1.42 — four numbers.

A web page isn't allowed to scan your network (your phone blocks that for security), so it needs the address once — then it's saved.

Update my Jooki

For a Jooki that already runs OpenJooki. One tap — it fetches the newest version from GitHub and installs it if there's something newer.

Update now
Tapping is always safe. A new tab opens showing just the word ok — that's your Jooki saying « got it ». Close that tab, you're done. If your Jooki is already up to date, nothing else changes — that's success, not an error. (A real update takes about 2 min and the Jooki restarts on its own.)
First time? Switch a factory Jooki to OpenJooki

Only for a Jooki that has never had OpenJooki. If yours already runs OpenJooki, use Update above instead.

Install OpenJooki (one tap)
A new tab opens showing ok (the Jooki received it). Your Jooki then downloads OpenJooki, installs it, and restarts on its own (about 10 minutes). Keep it plugged in. It cannot be bricked — it returns to your current firmware if anything fails. Only a Jooki v2 is accepted.
Why does it just say « ok »?

The Jooki's little on-device control only ever answers ok — it can't send a longer report back. And for security your phone won't let this page (served over https) read anything back from your Jooki (on http). So « ok » is the confirmation: the command reached your Jooki and is running. If you were already on the latest version, that's all that happens — and that's exactly right.

Under the hood your Jooki fetches the firmware straight from this project's GitHub release, checks it byte-for-byte (sha256), and installs it to the spare half of its storage. The bootloader only switches over if the new system is intact, and rolls back on its own if it fails to start. Your music, playlists and Wi-Fi are kept. Nothing is sent anywhere else.
