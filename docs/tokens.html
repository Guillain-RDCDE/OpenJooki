A sticker becomes a Jooki token

An NFC sticker already starts a playlist on OpenJooki. Written as a real Jooki token, it also pauses the music when you take it off, works twice in a row, and works on any Jooki, even one without OpenJooki.

You need
  • an NFC sticker NTAG213, NTAG215 or NTAG216 (the most common ones, a few cents each);
  • an Android phone with NFC switched on, and this page open in Chrome.

How it works

A Jooki token holds one web address, https://s.jooki.rocks/s/?s= followed by 16 characters. Those characters hide the kind of token and the sticker's own number, scrambled with a key the original Jooki program uses. The Jooki checks that the number inside matches the sticker it reads: a copy on another sticker is refused, so each sticker needs its own. The Jooki never visits that address.

This page writes the kind of token of the round flat tokens: OpenJooki gives each one a character of its own. Credits: the format was found by JookiTagCreator (MIT), and Muuselabs published it with the Jooki's source in October 2026.
